### Página do Site AnimeSpot
- Esse site será de história de animes, em que os usuários poderão ver animes, suas histórias, sinopses
 ### Página de login
- Está é a parte em que o usuário vai se logar para entrar no aplicativo
## Cores para o texto
- Crie um arquivo na cor de fundo um roxo/preto
- E a cor secundariacoloque como roxo
## Foto de perfil
- Crie uma foto em circulo para a pessoa colocar a imagem que ela preferir 
### Aba de Navbar
- Crie uma aba de navbar com os estilos das cores, mais predominante, no canto esquerdo colocar a logo que será essa: 
 - No canto superior direito colocar um texto escrito: Ja tem uma conta? Fazer login
## Caixa de texto para  login
- Crie uma imagem com a foto do logo do anime spot
- Em baixo crie um texto escrito: Boas vindas ao AnimeSpot em texto grande
- Em baixo crie um texto: faça login para continuar:
- Selecionar um texto escrito: E-mail
- Em baixo do texto vai ter uma caixa de texto para o usuario digitar seu e-mail
- Selecionar um texto escrito: Senha
- Coloque em baixo no canto inferior  Esqueceu sua senha?
- Em baixo do texto terá uma caixa de texto para o usuario digitar seu email
- selecionar um botão escrito: Entrar
- um texto escrito: Ou
- selecionar um botão escrito Criar uma conta
