# Histórias de Mangás e Histórias independentes de Mangás
- O contexto para essa página é de mostrar diferentes histórias de mangás ja criados anteriomente, como se fosse uma fandom e histórias de mangás criados de forma independente, criações próprias. 

## Formato da página
- Será feito uma tela que será linkada posteriomente com o index.html, lá o usuário poderá ver uma barra de pesquisa no topo direito, a pesquisa gerará uma resposta de quantas obras dispõem da pesquisa feita, ao lado da barra terá um ícone que ao clicar aparecerá vários genêros (esse será o filtro de pesquisa), por hora coloque genêros genéricos, terá logo abaixo da barra de pesquisa um um espaço retangular vertical exclusivo para a imagem do usuário, o seu nome e mais para baixo quais foram as histórias que esse usuário já leu, juntamente com um botão que linkará com uma página posterior de `histórico`
- No canto superior esquerdo, terá uma "flecha" ou algo semelhante que levará para a página anterior sendo o `index.html`, sendo nesse caso o menu principal
- Todo o espaço restante da página será dedicado às obras, a composição delas seria em formato de cards, esses cards terá a imagem do mangá, nome do mangá, o autor do mangá e o número de capitulos da obra.
- Tente deixar os card bonitos, no máximo 5 cards por linha, o ordem do card será, imagem - nome - autor - número de capitulos

## Instruções
- Todos os arquivos necessários já foram criados, sendo eles o *HTML* e *CSS*, ambos com o nome filtro_historia, use eles quando for criar o site
- Não use *javascript*
- Use como cor principal #15092E e como cor secundária #C384FF

### Correções
- Deve apresentar quantos capítulos cada uma delas está de acordo em qual capítulo o usuário está na leitura na aba de obras lidas
